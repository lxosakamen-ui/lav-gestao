Piloto iPhone — não usar em eventos reais. Esta versão começa sem os teus dados históricos. Importa apenas backups produzidos por este piloto; o backup antigo será migrado numa etapa própria, após auditoria. Guarda sempre os originais.

Primeiro circuito operacional

No iPhone, desliza o menu superior para aceder aos módulos e desliza as tabelas horizontalmente quando necessário. Este piloto permite registar produtos, contagens físicas, mínimos e transferências do armazém para os bares. Bares e Reposições utilizam a mesma função de stock atual.

Para experimentar: cria um produto, regista uma contagem no Armazém e outra num bar, define o mínimo e faz uma reposição. O stock é atualizado imediatamente nos dois ecrãs.

Não inclui ainda fecho de eventos, staff, Beerdrive integrado, compras nem migração dos 153 eventos. Essas funções não serão simuladas como se estivessem prontas.
