Primeiro circuito operacional

No iPhone, toca nos separadores do menu superior ou desliza-o para os restantes módulos. Se estiveres na pré-visualização da app Ficheiros, os scripts podem estar bloqueados; nesse caso a navegação não funciona. Para uso fiável é necessário publicar a aplicação num endereço HTTPS. No modo compatível, desliza o menu superior para aceder aos módulos e desliza as tabelas horizontalmente quando necessário. Este piloto permite registar produtos, contagens físicas, mínimos e transferências do armazém para os bares. Bares e Reposições utilizam a mesma função de stock atual.

Para experimentar: cria um produto, regista uma contagem no Armazém e outra num bar, define o mínimo e faz uma reposição. O stock é atualizado imediatamente nos dois ecrãs.

Não inclui ainda fecho de eventos, Beerdrive integrado nem gestão operacional completa do staff. O arquivo histórico dos 153 eventos está disponível apenas para consulta. Essas funções não serão simuladas como se estivessem prontas.
