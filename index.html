Definições e segurança

Backups

Exporta um backup completo antes de atualizar o ficheiro HTML. O Safari pode apagar dados locais; o GitHub não guarda as tuas alterações.

Nunca publiques backups com dados privados num repositório GitHub público.

Dados anteriores

A importação não apaga o que já está nesta versão. Guarda primeiro um backup.

Inventário inicial

Se quiseres começar a contagem do zero, usa as contagens rápidas. Não é necessário apagar as quantidades desconhecidas.
